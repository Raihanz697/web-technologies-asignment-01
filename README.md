Login & Registration Form 

A clean, responsive, and accessible Login and Registration Form built strictly using semantic HTML5 and CSS3—without any JavaScript dependencies.

✨ Features

Zero JavaScript Navigation: Seamless switching between the Login and Registration views using the CSS :target and :has() pseudo-classes.

Semantic & Accessible HTML: Every input field is paired with a properly associated <label> using matching for and id attributes.

Built-in Form Validation: Utilizes native HTML5 validation attributes (required, type="email", type="tel", etc.) and meaningful name attributes for backend processing.

Secure Submission: Both forms are configured to transmit data via the POST method.



📋 Included Form Elements

1. Login Form

Email Input (type="email", required)

Password Input (type="password", required)

Login Submit Button

Navigation Link to switch directly to the Registration Form

2. Registration Form

Full Name (type="text", required)

Email Address (type="email", required)

Password (type="password", required)

Phone Number (type="tel", required)

Date of Birth (type="date", required)

Gender Selection (Radio buttons: Male, Female, Other)

Skills / Interests (Checkboxes: HTML, CSS, JavaScript)

Division / City (Dropdown <select> menu with multiple options)

Short Bio (<textarea>)

Terms and Conditions (Required agreement checkbox)

Action Buttons (Submit and Reset)

Navigation Link to return to the Login Form

🚀 How to Run

Download or clone the project files into a local folder.

git clone: https://github.com/Raihanz697/web-technologies-asignment-01.git

Open the index.html file in any modern web browser (Chrome, Firefox, Edge, Safari).

Click "Register here" at the bottom of the Login card to switch to the Registration Form, and "Login here" to switch back.
