# Login & Registration Form

A clean, responsive **Login and Registration Form** built using pure **HTML5** and **CSS3**—with zero JavaScript. It uses the CSS `:target` pseudo-class to switch seamlessly between the Login and Registration views on the same page.

## 🌐 Live Demo

👉 **[View Live Project](https://raihanz697.github.io/web-technologies-asignment-01/)**

---

## ✨ Features

### 1. Login Form
- **Email Input** (`type="email"`, `required`)
- **Password Input** (`type="password"`, `required`)
- **Login Button** (`type="submit"`)
- **Navigation Link** to switch directly to the Registration Form

### 2. Registration Form
- **Full Name** (`type="text"`, `required`)
- **Email Address** (`type="email"`, `required`)
- **Password** (`type="password"`, `required`)
- **Phone Number** (`type="tel"`, `required`)
- **Date of Birth** (`type="date"`, `required`)
- **Gender Selection** (Radio buttons: Male, Female, Other)
- **Skills / Interests** (Checkboxes: HTML, CSS, JavaScript, Python)
- **Division / City** (Dropdown menu with multiple options)
- **Short Bio** (`<textarea>`)
- **Terms and Conditions** (Required agreement checkbox)
- **Action Buttons** (Submit and Reset)
- **Navigation Link** to return to the Login Form
